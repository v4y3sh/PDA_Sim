Theory

What is a Pushdown Automaton?

A powerful computational model that extends Finite Automata with an unbounded stack memory.

🤖

Informal Definition

A PDA is like a Finite Automaton but with a stack (LIFO memory). It reads input symbols one at a time and can push or pop symbols from the stack. The stack gives it more power — PDAs can recognize all Context-Free Languages, which FAs cannot.

🧮

Formal Definition

A PDA is a 7-tuple M = (Q, Σ, Γ, δ, q₀, Z₀, F) where:

  • Q — finite set of states
  • Σ — finite input alphabet
  • Γ — finite stack alphabet
  • δ — transition function: Q × (Σ ∪ {ε}) × Γ → P(Q × Γ*)
  • q₀ ∈ Q — initial state
  • Z₀ ∈ Γ — initial stack symbol
  • F ⊆ Q — set of accepting states
📚

Acceptance

A string is accepted if the PDA reaches a final state after reading all input (acceptance by final state), or if the stack becomes empty (acceptance by empty stack).

Transition Function δ

Each transition has the form: δ(state, input_symbol, stack_top) = (new_state, push_string)

Reading δ(q₀, a, Z₀) = (q₀, AZ₀) In state q₀, reading 'a', with Z₀ on stack → stay in q₀ and push A onto stack
ε-transition δ(q₁, ε, Z₀) = (q₂, Z₀) Without reading input, if Z₀ on top → move to q₂ (ε-move)

Example Languages

L = { aⁿbⁿ | n ≥ 1 }

Strings where the number of a's equals the number of b's. Example: ab, aabb, aaabbb

Strategy: Push one stack symbol for each 'a', then pop one for each 'b'. If stack is empty when input is exhausted → accept.

Balanced Parentheses

Strings of correctly matched parentheses. Example: (), (()), (()())

Strategy: Push for each '(' and pop for each ')'. Accept if stack empty at end.
